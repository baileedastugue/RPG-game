# RPG-game
Jurassic Park RPG game using JQuery

[Deployed Page](https://baileedastugue.github.io/RPG-game/)

*Goal of this application:*
- Create a role-playing game using jQuery
- Allow user to choose their fighter and next opponents
- Display dynamic health stats and fighter attack points

*Future developments:*
- Change the attack points for the different dinosaurs
- Implement a more aesthetically pleasing page using HTML and CSS

*Skills utilized:*
- jQuery 
- JavaScript
- HTML
- CSS
